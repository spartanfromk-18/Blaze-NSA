# Accessibility

The app uses Hindi-first labels, semantic headings, visible focus styles, keyboard-operable buttons and links, reduced-motion handling, chart labels/tooltips, and live status regions where applicable.

## Verification

Automated Lighthouse and axe runs are **UNVERIFIED** in this environment because Chromium is unavailable. A keyboard walkthrough (Tab, Enter/Space, and Escape where applicable) should cover district selection, priority toggles, rotation details, CSV download, and voice controls before release.
